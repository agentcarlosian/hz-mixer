# Security Policy

## Scope

Hz Mixer runs locally in the user's browser with no backend accounts or analytics.
Security fixes are applied to the `main` branch and included in subsequent releases.

## Reporting a Vulnerability

Please do not open a public issue for a suspected vulnerability.

1. Use GitHub's private vulnerability reporting feature for this repository if available.
2. Otherwise contact the maintainer at `carlosian@agentmail.to`.

Include the affected release or commit, reproduction steps, and expected vs. actual behavior.
