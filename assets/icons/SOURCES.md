# Icons

The bundled SVG icons are from the official [Lucide repository](https://github.com/lucide-icons/lucide), retrieved 2026-10-05. The original copyright and license notices are preserved in `LICENSE` in this directory. These files are served locally; the mixer makes no icon CDN requests.

Six additional icons (`star`, `download`, `upload`, `plus`, `arrow-up`, `arrow-down`) were retrieved from the same official repository on 2026-10-10. The same bundled licence notices apply.
