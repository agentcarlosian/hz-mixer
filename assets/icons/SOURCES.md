# Icons and Artwork

Utility/control SVGs are from the official [Lucide repository](https://github.com/lucide-icons/lucide), retrieved 2026-10-05 and 2026-10-10. Original ISC and inherited Feather MIT notices are preserved in [LICENSE](LICENSE). Files are served locally, without an icon CDN.

`info.svg`, `triangle-alert.svg`, `book-open.svg` and `arrow-left.svg` were retrieved from the same official repository on 2026-10-17. Only SVG whitespace was compacted; paths and attributes are unchanged. They use the existing Lucide licence notices.

`bell.svg` was retrieved from the official repository on 2026-10-18 for the interval-bell channels. Only SVG whitespace was compacted; paths and attributes are unchanged. It uses the existing Lucide licence notices.

`noise-pink.svg` and `noise-brown.svg` are recolored versions of Lucide's `audio-lines.svg`, made 2026-10-15. They retain the same paths and original licence notices, with pink and brown strokes respectively. Theme styling preserves these colors instead of inverting them in dark mode.

`waterfall.svg`, `stream-flow.svg`, `thunderstorm.svg` and `sea-waves.svg` are original Hz Mixer artwork drawn 2026-10-14 under the project's MIT licence. They depict a cascade, flowing stream, rain/lightning cloud and breaking sea wave. They are not modified Lucide icons.

`window-rain.svg`, drawn 2026-10-18 under MIT, is original Hz Mixer artwork depicting rain on a four-pane window. It is not a modified Lucide icon.

`campfire.svg`, drawn 2026-10-19 under MIT, is original Hz Mixer artwork depicting flames above crossed logs with small sparks. It replaces the generic flame symbol and is not a modified Lucide icon.

`mixer-waves.svg`, drawn 2026-10-15 under MIT, is the active header/favicon: a sloped three-channel console over a full-tile wave pattern. The opaque console masks the waves beneath it.

Only active icons are shipped. Unused design trials are not included in the source release or generated distributions.

`sliders-horizontal.svg` is from Lucide tag 0.468.0, retrieved from the official
repository on 2026-10-19 for source effects controls. Only whitespace was
compacted; paths and attributes are unchanged. It uses the existing Lucide notices.

`dices.svg` is from Lucide tag 0.468.0, retrieved 2026-10-19 from
https://raw.githubusercontent.com/lucide-icons/lucide/0.468.0/icons/dices.svg
for Randomize mix. Only whitespace was compacted; paths and attributes are
unchanged. It uses the existing Lucide notices.
