# Hz Mixer v0.1.0

Initial release candidate. Not yet published.

## Included

- Binaural, monaural, isochronic and nature-only mixing, with 0.01 Hz beat precision and 20-2000 Hz carriers.
- 37 presets, favorites and filters; fixed rates, sweeps and up to 16 session stages.
- Four CC0 recordings, three synthesized noise colors, per-layer level/mute/solo/balance and fades.
- Light, Green, black/purple Dark, Cyberpunk, Matrix and System themes, full-width theme-aware monitor and original mixer/environment artwork. Previous saved Dark selections migrate to Green.
- Browser-local libraries with JSON backup/import.
- Stereo WAV and MP3 export at 44.1/48 kHz; MP3 128-320 kbps, progress/cancel and optional direct-to-file saving.
- Static web distribution with lazy-loaded audio/encoder, plus optional self-contained offline HTML/ZIP.
- MIT original source/artwork, separate recording/icon terms and LGPL-3.0 encoder with full notices and corresponding source.

## Notes

No account, analytics, backend or flashing-light visuals. Website hosting still receives ordinary file requests; GitHub Pages logs visitor IP addresses for security. Saved libraries are specific to the browser and website/file location; transfer with JSON backup/import.

Frequency labels describe sound, not guaranteed mental states or health outcomes. Use stereo headphones for binaural playback and a comfortable volume. MP3 is lossy with codec delay/padding; WAV is the uncompressed reference. Exports render a current-settings snapshot, not past live edits, and are capped at two hours.

## Known Limitations

Long downloads can use substantial memory. Streaming Save As depends on browser support. Cancellation waits for the current rendering/decoding block. Automated browser tests use the built web app over HTTP; portable file-origin launch, native Save As and perceptual loop quality require manual acceptance. macOS/Safari/mobile listening and actual hosted CI/Pages are not verified by local checks.
