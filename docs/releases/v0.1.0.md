# Hz Mixer v0.1.0

Initial release candidate.

## Included

- Permanent one-step Restore previous mix command beside Reset/Dice, with disabled-unavailable state, in-memory snapshots and no saved-library changes.
- Precise percentage entry beside level sliders, clearer layered-tone/program summaries, band/method/program-aware search, keyboard/hover tooltips, reduced-motion-aware reset/dice animations and original campfire artwork.
- Dice-button random mixes beside Reset, with moderate channel levels, Simple/Advanced-aware settings and preserved master/mute, fades and program timing.
- Classic Simple mixer and optional Advanced mode in the same layout: three tone layers, fixed/follow/sweep programs, carrier bookmarks, finite-harmonic waveforms and harmonic blending, FM/PM, contextual source-effects popups, AM/stereo envelopes, auto-pan/balance and general audio filters.
- Envelope preview, monitor-only AM/dry A/B with optional RMS matching, and inline per-stage From/To changes for source crossfades, carrier, balance, AM depth and cutoff. Extended settings use version 6 JSON with older-format import retained; import capacity is 4 MB.

- Binaural, monaural, isochronic and Environment only mixing, with 0.10-120.00 Hz beats in 0.01 Hz steps and 1-5000 Hz carriers.
- 61 band-grouped presets, favorites and search; fixed rates, sweeps and up to 16 session stages. Includes 24 additional mixes featuring layered tones, AM/noise textures, dual-generator sweeps, staged crossfades and singing-bowl intervals.
- Six CC0 environmental recordings including Campfire and Window rain, three synthesized noise colors, per-layer level/mute/solo/balance and fades. Non-default Window rain settings use version 5 JSON; older formats remain readable.
- Two CC0 Tibetan bowl bells with independent repeat intervals, clock-aligned playback, channel controls and WAV/MP3 export. Non-default Campfire/bell settings use version 4 JSON so older builds cannot silently drop those layers.
- System, black/purple Dark, Light, Green, Blue and Matrix themes, full-width theme-aware monitor and original mixer/environment artwork. Previous saved Dark selections migrate to Green; saved Cyberpunk selections retain their palette under the name Blue.
- Pausable Matrix background code rain with kanji, katakana and vertical mixer vocabulary. Reduced-motion preferences, hidden tabs and other themes stop the animation. No strobes or beat-synchronized light effects.
- Browser-local libraries with JSON backup/import.
- Expanded-range mixes use version 3 JSON to prevent older builds from silently clamping frequencies; version 2 imports and ordinary-range exports remain compatible. Live playback checks the actual audio sample rate.
- Stereo WAV and MP3 export at 44.1/48 kHz; MP3 128-320 kbps, progress/cancel and optional direct-to-file saving.
- Static web distribution with lazy-loaded audio/encoder, plus optional self-contained offline HTML/ZIP.
- Header information dialog, comprehensive linked guide and a visible seated/reclined, no-driving-or-machinery listening warning. The portable HTML embeds the full guide.
- MIT original source/artwork, separate recording/icon terms and LGPL-3.0 encoder with full notices and corresponding source.

## Notes

No account, analytics, backend or flashing-light visuals. Website hosting still receives ordinary file requests; GitHub Pages logs visitor IP addresses for security. Saved libraries are specific to the browser and website/file location; transfer with JSON backup/import.

Use Hz Mixer while sitting or lying down in a safe place, never while driving, operating machinery or where reduced alertness or altered awareness could cause injury. Use stereo headphones for binaural playback and start at low, comfortable volume. MP3 is lossy with codec delay/padding; WAV is the uncompressed reference. Exports render a current-settings snapshot, not past live edits, and are capped at two hours.

## Reliability

Zero fade-out holds gain until the final stop, and pending asset loads no longer lock a cancelled export. Session editing preserves keyboard focus, modal dialogs expose accessible names, library import previews show capacity and preserve honest selection state, and preview serving validates canonical paths. Release verification compares built web/portable files with current source.

Generator export blocks use short matching-time overlaps to smooth low-carrier joins without changing duration. Delayed playback starts use the latest settings, including preset changes made during startup. Direct saves show a non-cancellable Finalizing phase while the browser commits the file.

## Known Limitations

Long downloads can use substantial memory. Streaming Save As depends on browser support. Cancelling detaches from pending asset loads; an already-running native render may finish its current block. Shared downloads may continue for playback/cache reuse. Automated browser tests use the built web app over HTTP; portable file-origin launch, native Save As and perceptual loop quality require manual acceptance. macOS/Safari/mobile listening and actual hosted CI/Pages are not verified by local checks.
