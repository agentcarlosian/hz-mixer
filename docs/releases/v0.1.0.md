# Hz Mixer 0.1.0

Initial release candidate for the offline Hz Mixer audio studio.

## Included

- Self-contained `Hz Mixer.html`, usable without a local server.
- Binaural, monaural and isochronic rhythms, precise 0.01 Hz beat entry, and 20-2000 Hz carrier controls.
- 37 presets across Delta, Theta, Alpha, Beta, Gamma and nature-only; filters, search and favorites.
- Fixed/sweep/staged programs, audio-clock pause/resume, fades and pulse shaping.
- Four bundled CC0 environmental recordings plus white/pink/brown noise.
- Independent mixer levels, mute/solo/balance and output monitoring.
- Saved mixes, JSON backups/import and 44.1/48 kHz stereo WAV export with progress/cancel.
- System/light/dark themes and responsive controls.
- Licence notices, asset provenance, manifest and SHA-256 checksums.

## Downloads

The ZIP contains the portable HTML and licence/provenance files. The standalone HTML is also provided separately. Verify either download against the accompanying `SHA256SUMS.txt`.

## Migration

Export a Library backup from the old Beat Mixer file before moving to Hz Mixer, then import it. Renamed/moved files may have separate browser storage. Legacy JSON formats and same-origin storage keys remain supported. Audio never autoplays after restoring settings.

## Known Limits

This tool does not promise a mental state or health benefit. Binaural mode requires stereo headphones; the meter is digital, not acoustic.

WAV exports are capped at two hours. Normal downloads retain encoded output in browser memory; direct-to-file streaming depends on browser support. Cancellation finishes after the current render/decode. Native file-origin playback and Save As behavior require manual browser acceptance. Local tests do not verify macOS/Safari/mobile listening or perceptual loop quality.

This document is a prepared candidate release description. Publishing requires a separate authorization, a verified hosted CI run and completion of the manual release checklist.
