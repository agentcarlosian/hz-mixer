Hz Mixer

Open "Hz Mixer.html" in a modern desktop browser. No installer, local server,
account or Internet connection is needed for the portable app. Audio begins
only after Play. Use stereo headphones for binaural mode and start at a
comfortable device volume.

All four recordings, icons, styles, code and credits are embedded in the HTML.
The other archive files document licensing, original audio sources and checksums.
The HTML can be used on its own without these companion files.

Moving from Beat Mixer: export a Library backup from the old file and import
it into Hz Mixer. Saved settings are browser/file-location specific. Renaming
or moving a file may start a separate library. The same JSON formats remain
supported. Theme settings are separate from audio backups.

Use Fixed, Sweep or Session to select a frequency program. Editing the manual
beat-rate field returns to Fixed. Editing a sweep or stage restarts the program
clock. Pausing preserves progress. The session length comes from its stages.

The export dialog offers WAV audio, Mix JSON and a Library backup. WAV output
uses current settings from the beginning, not past live edits. Long downloads
can use substantial browser memory; direct-to-file streaming is offered when
the browser supports it. Cancelling waits for the current render/decode block.

This is a listening and sound-design tool, not a medical device. Frequency
labels describe sound, not a guaranteed mental state or health outcome. The
meter measures digital audio, not volume at your ears. Stop if uncomfortable.
There are no pulsed-light visuals in this release.

Known acceptance gaps: automated playback tests use editable source over
loopback HTTP. Direct file-origin behavior and the native Save As picker need
manual checking in your browser. macOS/Safari/mobile listening and perceived
recording-loop quality have not been broadly validated.
